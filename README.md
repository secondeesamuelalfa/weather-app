# 🌤️ Weather App

A clean, modern, and responsive web application that provides real-time weather information for major cities around the world. Built with vanilla JavaScript, this app fetches live data from a weather API and features robust error handling and a beautiful, user-friendly interface.

## ✨ Features

- 🌍 **Multi-City Support**: Instantly fetch weather data for New York, Los Angeles, Chicago, Paris, Tokyo, and London.
- 🔄 **Real-Time API Integration**: Fetches live temperature, "feels like", humidity, wind speed, wind gusts, and weather conditions.
- 🛡️ **Robust Error Handling**: Gracefully handles API failures or missing data. Shows a friendly alert if a city's data is unavailable, and displays "N/A" for any undefined metrics.
- 📱 **Fully Responsive**: Adapts beautifully to mobile, tablet, and desktop screens.
- ⚡ **Zero Dependencies**: Built with pure, vanilla JavaScript—no frameworks, no build steps, no `npm install`.
